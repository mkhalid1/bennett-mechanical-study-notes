# Bennett Mechanical Study Notes

A free, complete study guide for the Bennett Mechanical Comprehension Test (BMCT-II): how the test works, the rules behind each of eight topics, 104 original practice items with full explanations and 45 diagrams, how scoring really works, and study plans for a week or a weekend. Written for anyone sitting the Bennett for a maintenance, production, engineering, apprenticeship or other technical role. Facts about the test come only from Pearson TalentLens and other primary pages, each one [cited](docs/sources.md).

Want to see where you stand first? Take the [free timed Bennett Mechanical practice test on PrepClubs](https://prepclubs.com/free-practice-tests/bennett-mechanical?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=bennett-mechanical), or the shorter [15-minute diagnostic](docs/diagnostic.md) in this repo.

## Start here

1. **Find your weak topics.** Take the [15-minute diagnostic](docs/diagnostic.md). It has three items from each topic and tells you where to start.
2. **Fix the weakest topic first.** Open its guide below, learn the rules and the method, then do its 10 practice items.
3. **Follow a plan.** Use the [7-day plan](docs/study-plans.md#7-day-plan), or the [2-day plan](docs/study-plans.md#2-day-plan) if your test link has already arrived.

## Quick facts

| | |
|---|---|
| Publisher | Pearson TalentLens |
| Questions | 55 |
| Time | 25 minutes, timed (about 27 seconds per item) |
| Delivery | Online, can be unsupervised. Desktop or laptop recommended. |
| Question pool | Drawn at random from an item bank, balanced for difficulty and content |
| What it measures | Problem solving, learning mechanical concepts quickly, basic mechanics knowledge, mechanical reasoning and spatial perception |
| Result | Ability (theta) score turned into a percentile against a norm group the employer chooses |

| Languages | Dutch, English (UK, US), Spanish, French |

Source: [Pearson TalentLens BMCT-II page](https://www.talentlens.com/bennett-mechanical.html), checked 24 November 2026.

## The eight topics at a glance

| Topic | The core rule | Guide |
|---|---|---|
| Levers and balance | Turning effect = force x distance from the pivot | [Levers](docs/sections/levers-and-balance.md) |
| Gears, belts and wheels | Meshing gears reverse direction. The smaller gear turns faster. | [Gears](docs/sections/gears-belts-and-wheels.md) |
| Pulleys, ramps, screws and wedges | Less force always costs more distance | [Pulleys](docs/sections/pulleys-and-inclined-planes.md) |
| Fluids and hydraulics | Pressure grows with depth. Narrow pipes flow faster. | [Fluids](docs/sections/fluids-and-hydraulics.md) |
| Heat and temperature | Name the process: expansion, conduction, convection or radiation | [Heat](docs/sections/heat-and-temperature.md) |
| Electricity | Trace the loop. Series breaks everything, parallel does not. | [Electricity](docs/sections/electricity.md) |
| Motion and forces | Objects keep moving straight unless a force acts | [Motion](docs/sections/motion-and-forces.md) |
| Sound, light, shapes and volumes | Equal mirror angles. Calculate volumes, never judge by eye. | [Sound, light, shapes](docs/sections/sound-light-and-shapes.md) |

Every topic guide has the same parts: what it measures, how the questions look, a step-by-step method, the traps that cost points, timing advice, 10 original practice items (most with a diagram) with explanations, and a score table.

## How to use this repo

- **Read on GitHub.** Every page has links to the previous page, the next page and back to these contents, so you can read it start to finish like a book.
- **Test yourself honestly.** Answers are hidden under "Answers and explanations". Commit to an answer before you open them.
- **Read every explanation,** including for items you got right. Most say why the nearest wrong answer is wrong, which is where the learning is.
- **Keep a miss log.** For each miss, write the rule you broke. The [study plans](docs/study-plans.md#how-to-review-a-missed-item) show how.
- **Practise timed.** The notes teach the rules. A timed run, such as the [free one on PrepClubs](https://prepclubs.com/free-practice-tests/bennett-mechanical?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=bennett-mechanical), teaches the pace.
- **Clone or fork it** if you want your own annotated copy. The diagrams are plain SVG files in [assets](assets), and the structure also works as a GitBook space: see [SUMMARY.md](SUMMARY.md).

## About the practice items

All 104 practice items and all 45 diagrams are original, written and drawn for these notes. None are taken from the Bennett Mechanical Comprehension Test, from Pearson's materials or from any prep site. They follow the physical principles the test is built on, so the method you learn here transfers to the real test.
